# Trabajo Final AutoWeb Galaxy

Proyecto de automatización web desarrollado como trabajo final del curso **Selenium Test Automation**.

## Alumno

**Richard Paul Saucedo García**

## Aplicación bajo prueba

[Magento Testing Playground](https://github.com/lruizajax/magento-testing-playground)

El entorno se ejecuta mediante Docker Compose y queda disponible en `http://localhost:8081`.

## Alcance

El proyecto automatizará los 15 casos solicitados para los módulos de registro, inicio de sesión y creación de órdenes.

## Base técnica

- Java 21
- Maven
- Selenium WebDriver 4.45.0
- TestNG
- Page Object Model
- Allure Report

> La documentación completa se incorporará cuando finalice la implementación de los casos de prueba.
